# ₿ BitcoinPulse – Bitcoin News Blog

A fully SEO-optimised, ad-ready Bitcoin news website that auto-cycles live stories from top crypto news sources.

## 🚀 Live Demo

Deploy via **GitHub Pages**: Go to `Settings → Pages → Source: main branch / root`

Live at: `https://reluctant-coder-oss.github.io/bitcoin-news-blog/`

## ✨ Features

- 📰 **Live News Feed** – Auto-fetches from CoinTelegraph, Bitcoinist & NewsBTC via RSS
- 💰 **Live BTC Price** – Real-time USD & GBP price with 24h change (CoinGecko API)
- 📈 **Price Charts** – 7-day mini chart in sidebar + full chart on Markets page
- 📢 **Ad Slots** – Pre-wired 728x90 leaderboard, 300x250 and 300x600 sidebar placements
- 🔄 **Breaking News Ticker** – Auto-scrolling headline ticker
- 📬 **Email Signup** – Newsletter capture widget
- 🔍 **SEO Optimised** – Meta tags, canonical URLs, Open Graph, Twitter Cards, JSON-LD, sitemap.xml, robots.txt
- 📱 **Mobile Responsive** – Works on all screen sizes
- ⚡ **Auto-refresh** – Price every 60s, news every 5 minutes
- ✅ **Coinzilla Verified** – Crypto ad network integrated

## 💡 How to Monetise

1. **Coinzilla / Bitmedia** – Crypto-specific ad networks (higher CPMs for crypto audiences)
2. **Google AdSense** – Replace `ad-placeholder` divs with your AdSense code
3. **Affiliate Links** – Add Kraken, Ledger, or Binance affiliate banners
4. **Sponsored Posts** – Sell article placements via direct outreach

## ⚙️ Tech Stack

- Pure HTML5 / CSS3 / Vanilla JavaScript (no framework)
- CoinGecko API (free tier)
- rss2json.com (free RSS-to-JSON proxy)
- Google Fonts (Inter + Space Grotesk)
- GitHub Pages (free hosting)
